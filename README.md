# Times

A small native macOS clock app (Swift + SwiftUI, ~3 MB) with the features of Apple's Clock app,
styled like V3ERA's desk widgets: paper cards, black ink, hairlines, tiny tracked monospace labels,
Avenir Next Condensed numerals and one yellow signal color. Light, dark or system appearance.

## Build

```bash
./build.sh            # -> build/Times.app
./build.sh --install  # also copies to /Applications
```

Requires Xcode (the SwiftUI macros aren't in the Command Line Tools).

## Features

- **World Clock**: a dot-matrix world map with the live day/night terminator, the sun and a
  marker per city. Cities show as a list (drag to reorder) or as analog dials (white by day,
  black by night), with "Today, +6 HRS" offsets. Search all IANA zones plus common city aliases.
- **Alarms**: time, repeat days (with Weekdays/Weekends/Daily shortcuts), label, sound, snooze.
  One-shot alarms turn themselves off after ringing. The side card shows the next alarm on the
  V3ERA black time face.
- **Stopwatch**: digital or analog (60 s dial, 30 min subdial, lap hand), laps with best/worst
  highlighted. Keeps running across relaunches. Space = start/stop, L = lap, R = reset.
- **Timers**: several at once, each with a label and sound; pause, +1 min, cancel; presets,
  recents, and a V3ERA-style quick field (`7:30`, `20m`, `1h 15m`, `90s`).
- **Ringing**: alarms and finished timers ring in a floating widget on every Space, with
  Snooze / Repeat / Stop, looping the chosen system sound.
- **Menu bar**: countdown or stopwatch in the menu bar, plus a panel with timers, next alarm and cities.
  Closing the window keeps Times running so alarms still fire.
- Alarms and timers are also scheduled as notifications, so they still go off after you quit.

## Shortcuts

| | |
|---|---|
| ⌘1…4 | World Clock / Alarms / Stopwatch / Timers |
| ⌘N | Add city / new alarm / focus timer field / lap |
| ⇧⌘S / ⇧⌘L | Start–stop / lap–reset stopwatch |
| ⌘, | Settings (appearance, 24-hour time, seconds, menu bar, snooze length) |

Design tokens live in `Sources/Times/Theme.swift`. The app icon is drawn by `scripts/make-icon.swift`
in the same style as LBrowser's (white squircle, dot-matrix shape, amber dot). The land mask in
`Sources/Times/WorldMask.swift` is generated by `scripts/make-mask.swift`.
